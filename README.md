# Wells-Tents

Chapter 1 FoldMap vertical slice for Godot 4.3+. Assign under-shepherds on the fold: Idle → Walk → Busy, with a fail-capable Days 1–30 sim.

## Open in Godot

1. Install Godot 4.3 or newer.
2. Import `project.godot` (Project → Import, then select this file).
3. Press F5. The main scene is the FoldMap.

Headless sim checks: `godot --headless --path . -s tests/run_sim_tests.gd`. See `RUN.md`.
